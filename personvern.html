Personvern og data

Her kan du lese om kva informasjon RunGoal lagrar og korleis dataa dine blir behandla.

1. Kva data blir lagra?

RunGoal lagrar informasjon som hjelper deg med å følgje framgangen din:

  • Løpemål og treningsplan
  • Distanse og tid på løpeturar
  • Dato for løpeturane
  • Korleis løpeturen kjendes
  • Treningshistorikk og statistikk

2. Kor blir data lagra?

Treningsdata blir lagra lokalt på mobilen eller PC-en din ved hjelp av LocalStorage. Dataa blir ikkje automatisk sende til ein ekstern RunGoal-server.

Data blir heller ikkje automatisk synkroniserte mellom ulike einingar.

3. Deling av informasjon

RunGoal ber ikkje om namn, e-postadresse eller GPS-posisjon.

GitHub Pages blir brukt til å publisere appen. GitHub kan samle inn teknisk informasjon, som IP-adresser, i samband med drift og tryggleik.

4. Sletting av data

Du kan fjerne lagra treningsdata ved å slette nettstaddata for RunGoal i nettlesaren. Ver merksam på at dette også kan fjerne andre lagra innstillingar i appen.

5. Trygg bruk

Bruk helst RunGoal på ei eining du sjølv har kontroll over. LocalStorage er ikkje kryptert som standard, så unngå å lagre sensitive opplysningar i appen.

Hugs: Treningsdataa dine blir lagra lokalt på eininga di. Dersom du byter mobil eller nettlesar, blir dataa ikkje automatisk overførte.
